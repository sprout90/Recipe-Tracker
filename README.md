# Recipe Tracker

Recipe Tracker is a React application developed as part of the Thinkful Software Engineering program. The project focuses on fundamental React UI development techniques including component composition, one-way data flow, props, event handling, controlled forms, and state management.

## Application Overview

The application maintains a collection of recipes in React state. Users can add recipes through an interactive form and remove existing recipes, with the interface updating in response to each action.

The application demonstrates:

* Parent and child React components with focused responsibilities
* State management using the `useState` hook
* One-way data flow between components
* Passing data and event callbacks through props
* Controlled form inputs
* Create and delete event handling
* Rendering collections of data as reusable components
* CSS-based layout and presentation

## Thinkful Project Context

Thinkful provided a pre-built React application with starter components, basic scaffolding, initial recipe data, and most of the required CSS.

My work focused on completing the application behavior and presentation. This included implementing application and form state, connecting parent and child components, passing data and callbacks through props, handling create and delete events, rendering individual recipes, and completing the application's styling.
